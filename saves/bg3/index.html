Baldur's Gate 3 Save File Location (Windows & macOS)

Baldur's Gate 3 stores its save files at %LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\PlayerProfiles on Windows. Checkpoint64 already knows this folder — it backs it up automatically and keeps every version, so a corrupted or overwritten save is one click from restored.

Where Baldur's Gate 3 saves are stored

  • Windows — %LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\PlayerProfiles
  • macOS — ~/Library/Application Support/Larian Studios/Baldur's Gate 3/PlayerProfiles

The save data here is .lsv / .lsfx / .lsf / .lsb / .png / .webp / .json / .savebackup files — back up the folder as a set, not single files, so a restore always keeps them consistent.

How to open the save folder

  • Windows — press Win+R, paste %LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\PlayerProfiles, and press Enter.
  • macOS — in Finder press Cmd+Shift+G (Go to Folder) and paste ~/Library/Application Support/Larian Studios/Baldur's Gate 3/PlayerProfiles.
